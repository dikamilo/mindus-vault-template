# output/synthesis

Material derived from existing notes — a comparison, a distillation of a hub, a reconciliation of a contradiction, a generated document. Written by `synthesize`, partitioned to `outputs/synthesize/` and kept indefinitely by default (`retention: keep`).

A synthesis is an artifact, not knowledge: `synthesize` never writes to a content layer. If a synthesis proves durable enough to want as a permanent note, promote it deliberately via `capture` — nothing does this automatically.
