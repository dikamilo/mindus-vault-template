# meta/preset

Marks a `preset.yaml` under `meta/presets/` as an installable bundle — a layer preset (`layers/`) or a vocabulary preset (`vocabulary/`). See `system/skills/configure/references/preset.md` for the format and the validation `configure` runs before installing one.
