# content/journal-entry

A dated personal entry, written directly rather than distilled from a source. No hub grammar applies — the `journal` layer is `flat`, so entries are peers identified by their date rather than filed under a hub. Write in whatever register the journal voice file sets; this is the one layer where the entry itself, not just hub prose, may read informally.
