# content/area

The hub tag for the `areas` layer's one enforced level: an ongoing responsibility — health, finances, a relationship, a role — that does not have an end state the way a project does.

Its prose reads like a project hub's, minus the lifecycle: what this area covers, what matters in it right now, and links to the notes that carry real weight. Installing this preset also brings `content/concept` into scope here, since ordinary atomic notes live under an area the same way they do in `knowledge` — see `preset.yaml`.
