# content/source

Primary material kept for its own sake below a collection — a lesson
transcript, a set of prompts, an exercise file. `require_exactly_one: false`
in this layer, so a file may carry this tag alongside others or none at all;
non-markdown files inside a collection are exempt from tagging entirely.
`language: any` applies here — a Polish course stays Polish; only the shelf and
collection hubs above it are English.
