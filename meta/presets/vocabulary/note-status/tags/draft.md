# status/draft

The note's writing is not yet settled — content or structure may still change
materially. This is a **note-status** marker, about how finished the writing
is, and is unrelated to any layer's own `lifecycle:` field (design spec
§11.7), which tracks whether an *item* like a project is active or archived.
Applied by hand; no skill sets or clears it automatically.
