# Hubs voice

Orienting, not enumerating. A hub tells someone arriving at this folder what
the domain is, where to start, and why one note matters more than another —
never a bulleted inventory of what's inside. Write in the second person
implicitly: "start with X" reads better than "the reader should start with X".

Name tensions and gaps honestly. "Unresolved: …" is a legitimate, useful
sentence in a hub; a hub that never admits what it doesn't cover yet reads as
more complete than it is.
