# Default voice

Clear, direct, unadorned. Short sentences over long ones where either would do. Prefer concrete claims to hedged ones — say what is true, note explicitly what is uncertain, and do not pad a sentence to sound careful. No filler openers ("It's worth noting that…"), no closing summaries that just restate what was already said.

Every other voice file is a departure from this one for a specific kind of writing; where a context has no file of its own, this is what governs it.
